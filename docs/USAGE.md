# 使用说明

安装步骤见 [项目首页](../README.md#快速启动windows)。安装完成后运行 `run.cmd`，打开 [复习工作台](http://127.0.0.1:5173/)。

## 启动与模型配置

在右上角点击“模型配置”，在左侧添加服务商，在右侧填写接口根地址和 API Key。通过内置目录添加模型，或点击“手动添加模型”填写准确的模型 ID；每个服务商可以保存多个模型。

选择模型后，点击“选择用于复习”，再点击“保存配置”。左侧切换服务商只切换编辑对象，保存后才更改实际使用的模型。未接入的服务商可先作为草稿保存；使用中的模型必须具备完整连接信息。保存后的配置立即生效，无需重启。

“检查所选模型”会发送一次文字请求，可能产生 API 费用，不保存或切换配置。“获取服务模型列表”只向 OpenAI 兼容服务请求 `/models`；列表不提供的视觉、推理和 token 上限需要自行确认。带图题需启用模型实际支持的图片输入能力。

使用 Ollama 或 LM Studio 时，可在添加连接处选择对应本地服务，默认填写常用接口地址并选择“无需密钥”。例如 Ollama 使用 `http://127.0.0.1:11434/v1`，模型 ID 应与本机已安装的模型一致。

更多凭据、推理设置与兼容参数见 [模型配置说明](MODEL_CONFIG.md)。

已有模型订阅时，在左侧“添加连接”中选择“模型订阅登录”分组的服务，点击登录按钮并按授权链接或验证码提示完成登录，再从内置目录添加模型、选择用于复习并保存。已有的对应服务商也可以把“接入方式”切换为“模型订阅登录 / OAuth”。

“删除服务商”和“移除模型”在配置窗口底部确认后立即生效，无需再次保存；其他未保存的编辑内容会保留。

## 上传资料与生成笔记

1. 创建课程，上传课件、笔记或试卷；真题填写年份，同批文件选择相同资料类型。
2. 等待“可用于复习”，通过原文预览查看解析内容。
3. 在目录中排序、改名或合并章节，确认后生成复习笔记。
4. 查看生成结果，按需下载 Markdown。

支持 PDF、DOC/DOCX/RTF、PPT/PPTX、文本、Markdown 和常见图片，单文件上限 50 MB。DOC/PPT/RTF 需要安装 JDK 和 Tika；首次解析可能下载 OCR 或向量模型。

切换课程时只加载资料列表、块 ID 和章节归属等轻量数据；点击“原文预览”时才读取所选资料的完整解析正文。

新增、删除资料或调整目录后，旧笔记会标记过期，可重新生成。需要重新提取文字和公式时，点击资料的“重新解析（OCR）”。

“章节目录”放在课程侧栏与笔记卡片之间的空白区域，不占用笔记正文宽度，默认只显示大章节。点击标题旁的箭头可逐层展开或收起小章节，点击标题跳转到正文；两者之间的空白不足时，点击笔记上方的“章节目录”打开目录浮层。阅读位置会自动保存在当前浏览器，重新打开同一份笔记后可点击“继续上次阅读”。选中正文中的一段文字，点击“解释这段”，右侧对话会带上该笔记版本、章节和对应段落；可以继续追问，也可以取消段落上下文。

## 复习问答

新建对话后，直接提问知识点或查找往年题目，也可以继续追问。检索范围为当前课程的资料，左侧切换课程即可切换复习内容。

讨论试题时，只有核验过试卷、题号、题干或选项对应关系的答案才作为原文答案。仅检索到某份答案文件不会证明它对应当前题目；无法核验时会说明不足。核验复用在线练习中已经准备好的答案匹配结果。

## 学习记忆

右上角“学习记忆”可查看、修改或忘记学习偏好、当前课程的知识点记录和会话摘要。全局偏好跨课程使用，课程偏好仅用于当前课程；明确的长期讲解要求会自动保存，较长会话会在后台整理摘要，原始聊天仍保留。

选择题作答和错题重练会按知识点整理学习记录，模型参考答案判定的错误会标明依据。记忆帮助接续话题、调整讲解和选择薄弱点练习，不作为知识或标准答案的证据。

## 复习空间

1. 进入“复习空间”，在聊天框输入想复习的内容，例如“复习树”或“讲讲 Cache 地址划分”。默认检索当前课程全部课件和笔记，新对话也可限定章节。
2. 通过聊天追问、让助手换一种讲法，或一起梳理知识点。无需设置时间和题数，不会强制进入做题流程。
3. 想做题时直接发送要求，例如“给我3道栈的简答题，难度中等”。支持单选、多选、简答或计算题，一批1–10道，按本次要求生成并逐题展示；不限定刚才讨论的知识点。可作答、查看参考答案，也可以选择“先不做，继续聊”。助手只依次展示本次要求的题目，不擅自生成额外题目。
4. 对话自动保存，可从左侧复习记录继续、重命名或删除。重命名只修改记录标题；删除仅移除该复习对话，独立保存的练习、错题和学习记录仍保留。点击“结束对话”保存小结；没有做题也能正常结束。

单选、多选题按已保存答案比对作答，判题依据始终保留；简答和计算题保存文字作答，供对照参考答案，不自动判定对错。已有题目需已保存可用答案；用户要求出新题时，按本次要求生成。新题使用模型参考答案，选择题作答差异会按现有规则收入错题本。

助手优先使用课程资料；资料不足但模型已有相关知识时，可直接补充并注明“含模型已有知识的补充”。仍不确定、需要核对或需要最新信息时，才调用联网搜索兜底，不要求每次资料不足都联网。使用了联网内容的讲解、题目和解析会注明“含模型自行搜索的知识”，并保存真实来源链接；进入在线练习或错题本后标记仍保留。模型补充与联网知识均不作为上传答案或考试标准答案，与课程口径有差异时优先课程资料。

联网搜索默认使用 Bing 公开搜索结果，不需要额外 API Key；只发送通用知识点检索词。可展开讲解依据查看网页摘录或搜索结果摘要。需要后端可访问互联网，搜索失败会记录原因，由助手调整安排，不会声称已经取得联网资料。

未使用提示、未看过答案的新题作答会单独记录；原题重做或一次答对不等同于已经掌握。可展开“查看助手操作”查看行动理由和结果。

新版聊天记录、待答题目和选择保存在本机，刷新后可接续；后端重启后，继续发送消息即可复习。旧版记录仍可查看当时保留的最新讲解和作答。课程资料或答案关联变化后，需要新建复习对话。

批量生题每完成一道并通过校验，就保存该题及原始出题要求。失败或后端重启后，点击“继续生成剩余题目”接续当前批次，已完成的题目不会重新生成。发送新的要求或更改章节范围会放弃未完成批次；课程资料变化后需要新建复习对话。

## 在线练习

“AI 生题”支持选择章节、填写知识点，或按本课程记忆中的薄弱点生成练习，可设置 1–10 题、题型和难度。知识点可用逗号或换行分隔；选择多个章节或知识点时，题数需足够逐个覆盖。“我的薄弱点”不勾选时优先练习错误次数较多的知识点，也可手动指定。

生成过程显示进度，每道题通过校验后保存。失败或后端重启后可“重试生题”，从尚未完成的题继续，并保持原有出题要求及薄弱点方向；课程资料版本变化后会重新生成整批。整批完成后即可作答。AI 练习保存在“我的练习”下拉列表中，参考答案和解析由模型生成，选择题可提交作答，简答／计算题自行对照；作答进度及错题收录沿用现有流程。AI 练习不进入资料库或章节目录。

1. 进入“在线练习”，上传题目；答案在独立文件中时，再上传答案。
2. 等待解析并整理题目，在“试卷答案关联”中选择对应答案文件。
3. 选择或输入作答，提交后查看结果与解析；其他题型可点击“显示答案”自行对照。

在“我的练习”中选中试卷或 AI 练习，点击“改名”并保存，刷新后名称仍会保留。改名保留题目、答案关联和作答进度。

选择题区分“上传答案”“原题自带答案”和“模型参考答案”，按对应答案判题并标明依据；与模型参考答案不一致也会记为错误，模型答案仅供参考。英文题目可点击“翻译题目和选项”。作答进度自动保存，刷新后可继续。

## 错题本

选择题答错或与模型答案不一致时会自动收录；其他题目可手动“加入错题本”，也可直接添加错题。答对后原错题仍保留，复习完成可手动移除。

点击“重新作答”会隐藏旧作答和解析，提交后保存一条独立的重练记录，再显示参考答案。选择题按已保存的原文答案或模型参考答案判题，并标明依据；非选择题保存作答后自行对照。点击“结束重练”可查看历次记录，原来的错误作答仍保留。

每道错题的“讨论这题”会将题目和当前重练作答（未重练时为最近一次作答）带入右侧对话。原试卷删除后，仍可使用错题快照重练或讨论；没有保存参考答案时不会自动判分。

## 数据与常见问题

- 数据与上传文件保存在 `data/`，密钥保存在 `.env` 或 `data/model-config.json`，请勿分享；重要资料自行备份。
- 生成、翻译和问答会向所配置的模型服务发送必要的文字或题图。
- 解析失败可重试；无法识别的图片或公式会自动跳过，必要时换用更清晰的资料。
- 出现索引修复提示时，等待上传处理结束后点击“重新建立索引”。
- 升级后首次知识检索会从已保存文本整理整页/小节索引，不需要重新上传；综合对比会分主题检索与重排，可能需要更长时间。实际材料与缺项可查看[检索说明](RETRIEVAL.md)。
- 课程和会话支持改名与删除，题目可在练习中删除；删除课程会清除其关联数据。
- 需要重启后端时，先等待正在处理的任务结束，再运行 `run.cmd`。后台日志位于 `.cache/run/`。

也可手动在两个终端分别启动，停止时按 Ctrl+C：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

```powershell
cd frontend
npm.cmd run dev -- --port 5173 --strictPort
```
