# 知页 Windows 便携版

适用于 Windows 10/11 64 位。无需安装 Python、Node.js、Java 或 npm；包内包含运行环境、前端页面、Granite 向量模型、文字与公式 OCR 模型和 Tika。模型聊天、生成笔记、出题及订阅登录仍需联网并使用你自己的模型服务。

## 使用

1. 从 GitHub Releases 下载 `Zhiye-版本-windows-x64.zip`，**完整解压**到普通本机目录，不要在压缩包内运行。
2. 双击 **启动知页.cmd**，等待浏览器打开 `http://127.0.0.1:8000/`。
3. 在右上角“模型配置”添加你自己的模型服务；然后创建课程、上传资料。
4. 使用期间保持启动窗口打开。退出时先等待上传或生成任务结束，再在窗口按 `Ctrl+C`。

若浏览器没有打开，可手动访问上述地址。启动失败时窗口会保留错误；详细日志在 `%LOCALAPPDATA%\Zhiye\logs`。8000 端口被开发版或其他程序占用时，请先关闭占用程序。该包使用浏览器界面，并没有独立桌面窗口。

## 数据与升级

课程、上传文件、会话、练习进度、API Key 和订阅凭据保存在 `%LOCALAPPDATA%\Zhiye\data`，不保存在解压目录。备份时复制整个 `%LOCALAPPDATA%\Zhiye`，其中包含你的私密凭据，请勿上传或分享。

更新时停止旧版，将新版解压到新目录，运行新版的启动文件；新版会沿用同一用户数据目录。不要同时运行两个版本。不要删除用户数据目录，也不要直接用旧版程序打开新版修改后的数据库。

便携版不会自动导入开发目录的 `data/`。若要搬入已有资料，请先停止开发版和便携版、备份双方数据，再把开发目录下完整的 `data` 文件夹复制到 `%LOCALAPPDATA%\Zhiye\data`；不要合并两套数据库。浏览器本地保存的临时草稿不会随数据库迁移。

## 发布范围

发布包不包含作者的 `.env`、课程文件、数据库、API Key、OAuth 凭据或个人模型配置。公开模型和第三方组件按各自许可证提供；许可文件位于 `third-party/`、Python 包的 `.dist-info/`、Node 包和 Java 的 `legal/` 目录。

本次仅完成打包，未运行程序、自动测试或干净机器验证；实际启动、上传解析、公式 OCR、模型调用和升级请由使用者验证。该版本没有宣称通过运行验收。

## 开发者重新打包

在源码目录继续开发，安装依赖使用现有 `scripts/setup.ps1`。打包前准备可再分发的 Temurin 完整 JDK（脚本用 jlink 只打包 Tika 用到的模块，并预编译 DOC 辅助类），以及 `.cache/packaging/formula` 下四个公开公式模型、`.cache/packaging/notices` 下许可声明。向量模型使用项目固定的 Granite 快照，文字模型位于已安装 RapidOCR 的 `models` 目录。

```powershell
.\.venv\Scripts\python.exe .\scripts\build-portable.py --version 0.1.0-portable.1 --java-home "可再分发的Temurin-JDK目录"
```

脚本只编译前端、收集依赖和资源、生成 ZIP 及 SHA-256 文件，不运行测试或启动验证。发布产物在 `dist/`，不进入 Git 版本控制。已有同名版本目录会阻止覆盖，请为下一次打包指定新版本号。发布前自行验证；不要把未验证标记改为已验证。
